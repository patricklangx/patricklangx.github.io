QUICK GUIDE

Your files, your board.

Choose a local project folder. If it has no phases, KanbanRaum creates the four default phases To Do, In Progress, On Hold, and Done as folders. Existing default folders Backlog and Erledigt are automatically renamed to To Do and Done. Choose a dot color when creating a phase. Click an existing phase dot to change its color; the color is saved in the project. Use the icons in a column header to rename or delete a phase; at least one phase must remain.

📁 In Progress/└─ 📁 Update website/└─ 📄 task.md

Drag a phase handle (⠿) to another column to change its order. The order is saved in .phases.json in the workspace. Click a task to view its formatted Markdown description. Add subtasks when creating a work item; in its details, add, edit, check off, and delete them. The checklist is saved in subtasks.md for each work item. You can also add, edit, and delete comments; they are stored in comments.md in the work item folder. Use Edit to change the title, phase, and description. Paste images or attach files using the file picker. Attachments are stored under __data and appear as Markdown links. Removing an attachment link and saving deletes the unused file; an empty __data folder is also removed. Delete a work item to move it to __bin after confirmation. Use Empty trash in the sidebar and confirm again to delete its contents permanently. Work items created or edited on the board are saved as Markdown files. Drag cards into another phase to move them. Deleting a phase permanently deletes its folder and contents. The browser only remembers local folder access so the board can reopen next time; task content remains in files.
